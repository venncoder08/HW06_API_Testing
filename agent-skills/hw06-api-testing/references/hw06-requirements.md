# HW06 Deliverable Requirements

Use this checklist when reviewing coverage or preparing the submission.

## Per Selected API

- At least 35 atomic testcases.
- Domain partitions and boundary values for every applicable parameter.
- Applicable state transitions, security behavior, and response schema checks.
- Human audit with `VALID`, `INVALID`, or `INCOMPLETE` plus reasoning.
- At least five student-authored additions and an explanation of why AI missed them.
- Postman/Newman execution with `X-Student-Id` on every request.
- Real HTML reports and genuine defects reported in Markdown and GitHub Issues.

## Cross-Suite

- Postman feature list based on actual usage.
- GitHub Actions pipeline with a green run, a deliberately red run with one failed case, and recovery evidence.
- Excel testcases and summary.
- Self-drawn AI test-generator diagram plus pseudocode.
- AI Audit Report and 200-300 word AI critique.
- Main report in Markdown and PDF.
- Root README with self-assessment and counts for APIs, generated cases, student-added cases, executed cases, PASS, FAIL, and defects.
- Public repository link and final ZIP named `<StudentID>_HW06_AI_API_<SelfAssessedGrade>.zip`.

## Evidence Rules

- The student-ID header needs a Postman Console screenshot.
- Newman output must show the actual SUT hostname.
- The AI test-generator diagram must be drawn by the student, not generated by AI.
- Do not substitute a selected CI subset for the full suite without explaining the scope and grading risk.
